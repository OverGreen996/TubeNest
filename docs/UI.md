# TubeNest UI

依 UI／UX 技能的最小介面、平台一致性與深淺色配對原則調整；小型瀏覽器面板使用原生 HTML／CSS／JS，沒有額外 UI 框架、遠端字體或輪詢動畫。

- 384px 面板，4／8px 基礎間距；標題 20px、品牌 18px、內文 13–14px、輔助文字 12px。
- 淺色柔白，深色石墨灰，藍色用於唯一主下載動作與鍵盤焦點。語意色彩集中在 `extension/style.css` 的 CSS 變數。
- 原生畫質選單；重新讀取為次要圖示按鈕。保留上次選擇，讀取失敗隱藏過期選單，提示可重試。
- 一次一個下載；等待位置或工作進行時關閉重複啟動。進度來自 native 工作事件，不使用假百分比。
- 下載紀錄依狀態顯示取消、資料夾、錯誤與驗證完成；未開始下載不顯示驗證成功標記。
- 所有使用者標題、錯誤與紀錄使用 textContent；保留原有訊息來源及目前分頁驗證。
- 明確按鈕名稱與標籤、可見焦點、4.5:1 文字對比；支援 reduced-motion 與長文字換行。
- 網頁下載鈕維持 YouTube 原生膠囊形狀、分享旁 8px 間距，跟隨網站 dark 屬性。窄視窗只隱藏按鈕文字，錯誤提示仍可見。
- 使用說明依安裝、載入、下載排序；桌面兩欄，窄視窗單欄。
